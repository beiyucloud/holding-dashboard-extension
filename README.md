# 基金股票持仓看板（浏览器扩展版）

本地持仓盈亏 / 基金估值 / 价格异动 + 新公告 **桌面提醒**的 Chrome / Edge 扩展（MV3）。

所有数据只存在你自己电脑的浏览器本地存储里，**不上传任何服务器**。

## 功能特性

- 基金、股票实时盈亏与估值展示
- 涨跌幅异动提醒、基金 / 股票新公告提醒
- 桌面系统通知（扩展原生 `chrome.notifications`，比网页通知更稳）
- 单品种自定义阈值、单股票公告独立开关
点持仓里的**股票 / 场外基金名字**与**指数快照卡名字**都可弹出详情：股票是 分时 / 5日 / 日K / 周K / 月K / 季K / 年K + 12 项盘口 + 五档买卖盘（日K～年K 的图上会按**当前可见区间**标出最高 / 最低点数值，缩放平移实时重算；指数卡打开的是同一套弹窗，但指数无挂单簿、分时不画均价线，五档块自动隐藏），场外基金是「净值走势（近1月～成立来 6 档区间）/ 持仓明细（前十大重仓股：价格·涨跌幅·占净值比例·较上期）/ 基金概况（类型·规模·管理人·托管人·费率·业绩基准，其中「基金经理人」可点开看变动一览与现任基金经理简介）」三个视图，弹窗底部在该标的持仓内时还提供「加仓 / 减仓」直达入口（点开的交易弹窗自动盖在详情弹窗之上，不用先关掉详情）
- 数据全部存本地，零上传、零账号

## 安装（开发者模式加载，免上架商店）

1. 获取本仓库：
   - `git clone <本仓库地址>`，或
   - 点 GitHub 页面 **Code → Download ZIP** 解压
2. 浏览器地址栏打开：
   - Chrome → `chrome://extensions`
   - Edge   → `edge://extensions`
3. 右上角打开 **「开发者模式」**（Developer mode）
4. 点左上角 **「加载已解压的扩展程序」**（Load unpacked），选择本仓库根目录
5. 加载成功后，点工具栏拼图图标 🧩 把「基金股票持仓看板」钉到工具栏

## 使用

- 点工具栏图标打开看板 → **添加基金 / 添加股票**（输入代码即可）
- 进入 **设置**（顶部齿轮图标）：
  - 勾选「桌面通知」，点右侧「点击授权」→ 浏览器弹窗点「允许」
  - 「自动刷新间隔」设成 > 0（例如 `1`，代表每分钟）—— 这步必须有，否则不检查就不会提醒
  - 保存
- 把看板标签页保持打开（可最小化、可切到别的窗口），有异动 / 公告即弹系统通知

## 给朋友分发

- 直接分享本仓库链接，或到 GitHub **Releases** 下载打包好的 zip
- 朋友加载的是独立副本，数据互不干扰，看不到你的持仓

## 注意事项

- 开发者模式加载的扩展**不会自动更新**；升级时重新拉取代码、回扩展页点 🔄 重新加载即可
- 当前通知依赖「看板标签页保持打开」（监控跑在标签页内）；如需彻底关页也能弹，可把监控移入后台 `service worker`
- 行情使用东方财富 / 新浪 / 腾讯接口。

## 隐私

所有持仓、提醒设置仅存于本地浏览器存储（`chrome.storage` / `localStorage`），无任何网络上传行为。
